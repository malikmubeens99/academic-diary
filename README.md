# Academic Diary — Starter

This is Phase 1 of the project.

## What works now
- Responsive student dashboard
- Timetable display
- Class diary entries
- Assignment tracking
- Before/after class notification settings UI
- Browser notification permission + test notification
- PWA manifest/service worker foundation
- LocalStorage for demo data

## What comes next
1. Firebase Authentication
2. Firestore database
3. Firebase Cloud Messaging (real push notifications)
4. Timetable image/PDF/Excel AI analysis
5. Automatic reminder scheduling
6. Production deployment on Vercel

## Run locally
Open `index.html` in a browser for UI testing. For PWA/service-worker testing, use a local HTTPS/localhost server.

For the production version, the notification and AI API keys must NOT be placed directly in frontend JavaScript.
